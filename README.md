# Movie Management System

### Overview

The Movie Management System is a web application that allows users to manage movie records efficiently. It provides functionality to add, edit, update, and delete movie details such as title, release date, and poster.

## Features

🎬 Add Movies – Add new movies with title, release date, and poster.

✏️ Edit Movies – Modify existing movie details.

🔄 Update Movies – Keep movie information up to date.

🗑 Delete Movies – Remove movies from the system.

🖼 Poster Management – Upload and display movie posters.

## Tech Stack

Backend: Node.js, Express.js, MongoDB

Frontend: HTML, CSS, JavaScript, EJS

Development Tool: Nodemon

Installation

Prerequisites

Ensure you have Node.js and npm installed.

## Setup

Clone the repository:

```
    git clone https://github.com/Deeppatel-4032/Movie_Poster_db
    
```

cd movie-management-system

Install dependencies:

npm install

Start the development server:

npm run dev

Usage

Open http://localhost:8011 in your browser.

Add, edit, update, and delete movie records.

Upload and manage movie posters.
